# OpenRevo Native 0.6.9 · 机型适配、mini 自定义与稳定性修复

## 1. 模式切换与机型适配

- 修复部分已接管机型切换办公、均衡或狂暴模式时，对来源状态检查过严而中止操作的问题；目标参数、供电限制、写前状态比较和最终回读继续保留。
- 修正操作未完成时一律提示重新接管的情况，按实际接管状态反馈；诊断补充模式事务信息。
- 机身电源键旁的模式键接入性能控制，按 **办公 → 均衡 → 狂暴 → 办公** 循环。电池供电且未解锁时遵循已有可用档位限制。
- 自定义档仍由软件选择，并补充原厂白色模式指示。
- 累积无界 14 Pro / T140 的声明式能力、Fn 锁与单色背光适配；未知或不支持的能力不伪造为可用。其他机型仍以实际硬件协议与回读结果为准。

## 2. GPU 读取与状态总览

- CPU、GPU 磁贴增加型号行；超长名称单行省略，悬浮可查看完整型号。
- 修复 NVIDIA NVML 分支只提供指标、缺少型号字段的问题。型号与指标使用同一显卡句柄，不从另一张显卡补名。
- 纯集显和多个同名适配器场景结合活动内屏、适配器 LUID 与 Windows GPU 计数器确定读取对象；仍有歧义时保留未知。
- 完善 AMD 集显共享 GPU 内存、占用与频率读取，必要时使用匹配设备的 ADLX 频率后备。专用显存、共享 GPU 内存和系统内存继续区分。
- 显存单位标注统一为 **GB**，本轮不因改标签改变已有容量数值口径。
- 修正主窗口最小尺寸约束被框架覆盖的问题，最小宽度为 900 DIP，为顶部四列磁贴及后续模式、电池、屏幕卡片保留空间。

NVIDIA 型号修复不绑定单一机型，可复用于驱动及 NVML 兼容、满足既有采样条件的设备；AMD、Intel 继续使用各自现有路径。接口适用范围不代表所有机型、驱动和休眠状态均已实测。

## 3. 亮度、电池与电源

- 每次显示拓扑切换后合并通知，重新读取活动内屏及亮度；清除旧屏状态并丢弃过期结果，改善虚拟屏切回实体屏后一直无法读取亮度的问题。不增加闲置轮询。
- 拖动亮度条时，标题百分比即时跟随请求值；硬件提交与回读仍保留原有保护。
- 修复已验证 Project16 机型处于正常充电阈值组合时，电池档位被误判为不可调整的问题；其他项目及异常组合不扩大写入权限。
- 电池图的剩余电量、供电状态与充电上限文字移到图标下方；最小窗口下保持左右两栏，避免电池图整体换行下移。
- 纳入配置原子保存及电源系统 DLL 生命周期等选择性修复，保留现有本地适配和能力限制。

## 4. mini 自定义与拖动编辑

- 新增 mini 上方磁贴及六个快捷槽的自定义，支持排序、替换、移除和恢复；编辑使用独立草稿，保存后生效，预览不操作硬件。
- mini 与状态总览共用直接跟手、提前让位、平滑收束和稳定反向门槛；快捷区与控件库支持双向交换及撤销。
- 拖动项和交换项在页面根浮层呈现，越过预览、滚动区和控件库边缘时保持完整可见；手持项位于交换项上方。
- 修复编辑拖动阶段浮层层级值越界导致的闪退。取消、失焦、藏盘、离页及退出时清理浮层并恢复原项。
- mini 每次从托盘唤醒按当前工作区靠右下角，显示后仍可自由移动。

## 5. 大小面板切换与托盘

- 大小面板改用整窗淡化与沿实际两窗方向的轻微位移，标题栏、背景、内容和阴影保持一致，支持中途改向和减少动画设置。
- 面板快照采用逐行复制，减少切换时的大数组分配。此前隔离 A/B 场景观察到内存高水位下降；本发布未重新测量整机前后台长期内存，不将其写成普遍降幅。
- 托盘悬浮文字去掉时间及 CPU 的“温区”字样，保留现有状态与传感器读数。
- 后台功能与硬件接管继续保留，不依靠额外常驻进程实现这些界面变化。

## 6. 诊断、关于与版本

- “诊断与日志”新增 **提交 Bug**，打开本仓库 GitHub Issue 页面，预填问题模板和当前版本；用户在网页描述问题并上传原始日志附件。软件不要求或保存 GitHub 令牌。
- 关于页加入仓库网址、公开版本、赞助支持与交流群按钮，提供微信、支付宝赞助码及群二维码。

## 安装与升级

1. 从托盘菜单正常退出旧版，再运行 `Open-Revo-0.6.9-Setup-x64.exe`。
2. 沿用共享 **.NET 10 x64 Desktop Runtime** 与 **Windows App Runtime**，安装器保留运行时检测与下载引导。
3. 升级保留已有用户配置和自启选择。安装包约 **11.77 MiB**，完整 GPL 对应源码约 **2.74 MiB**。

**历史 0.6.8 仅更改了发布编号，原包内部仍为 0.9.8，因此可能不会自动提示升级到 0.6.9。请从本页手动下载安装；此后的 0.6.x 按正常数字规则比较。**

Release 下载附件只有安装包和完整对应源码；校验继续由本地发布记录与更新器使用。上传安装包与本次用户确认可用的测试包字节一致，未因发布重新编译。
