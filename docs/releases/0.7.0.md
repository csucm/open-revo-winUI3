# OpenRevo 0.7.0

[GitHub 发布页](https://github.com/csucm/open-revo-winUI3/releases/tag/native-v0.7.0)

### 开机自启热修复

修复登录时任务栏尚未就绪导致的自启弹窗和后台退出。登录自启延后 3 秒，手动打开仍即时启动。已安装 0.7.0 的用户可在软件内检查更新。 [热修复发布页](https://github.com/csucm/open-revo-winUI3/releases/tag/native-v0.7.0.0)。

### 藏盘后，后台占用更低

0.7.0 重构了 OpenRevo 的常驻内核。关闭窗口藏盘后，WinUI 面板进程退出，界面和总览的详细传感器采样随之释放。后台只保留处理托盘、设备事件和已启用策略所需的原生内核。性能档位、充电上限等已设置的功能可以继续工作，需要操作时点击托盘图标即可重新打开面板。

本机早期测试中，冷启动且未打开面板时，任务管理器曾显示后台低于 **5 MB**。打开面板后的占用还会受驱动和采样设置影响。少数情况下，开过面板再藏盘，后台内存会停留在约 **20 MB**。可用内存清理工具临时降低占用，计划在下一版本修复。

### 主要修复与改进

- **重启后恢复性能档位**。修复部分机型重启后回到默认档位的问题。设备与供电条件允许时，启动后会恢复上次已确认的原厂性能档位。
- **屏幕亮度与键盘灯光**。部分驱动未返回执行结果时，通过读取实际亮度确认是否生效。支持四档的键盘可直接选择关闭或 1–4 档，调节灯光时也减少了控件反复变灰和闪烁。
- **托盘温度与 GPU 功耗**。托盘 CPU 温度在驱动没有直接提供读数时可尝试读取 Windows 温区。总览只在需要显示读数时采样，NVIDIA GPU 功耗减少了反复初始化驱动接口带来的等待。

升级前请先从旧版托盘菜单完全退出 OpenRevo，再运行 x64 安装包。
