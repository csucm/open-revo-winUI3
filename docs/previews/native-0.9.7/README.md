# Native 0.9.7 previews

Rendered from the 0.9.7 sources in an isolated, ordinary-permission WinUI host. Hardware takeover and telemetry polling were disabled. The host window remained DWM-cloaked. These are XAML client-area previews; system caption buttons and desktop backdrop are not included. Unknown hardware values are placeholders, not measurements.

The plugin screenshot demonstrates an in-development API and built-in example. Third-party installation, legacy web plugins and the plugin market are unavailable.
