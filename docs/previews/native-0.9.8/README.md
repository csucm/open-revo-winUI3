# Native 0.9.8 界面截图

这些图片由 0.9.8 对应源码的独立、隔离数据、只读宿主通过 WinUI RenderTargetBitmap 导出。截图宿主只增加截图调用，没有改动本次发行文件，没有硬件接管或硬件写入。

包含浅色/深色总览、浅色/深色 mini、磁贴编辑、灯光、OSD 设置、设置页上半区域及插件开发页面。未连接硬件的指标以未知显示；插件摘要中的 52°C、76% 已在界面标为“人工示例”，不是实机数据。设置与编辑图为当时视口内容，下方区域可在大面板滚动查看。

图像包含 XAML 客户区，不包含 Windows 系统绘制的外框和标题栏按钮。OSD 图为设置页内预览，不是桌面悬浮窗口的透明度实测。

这些图片说明当前页面外观，不用于证明所有 DPI 下的逐帧流畅度、硬件兼容性或内存降幅。
