与普通完整包相比减少 45.2%。与同压缩等级完整包相比减少 44.3%。基线和候选均含对应源码；最终候选另补许可及复现资料，比较有少量资料差异。
发布运行目录 76,546,985 字节，264 文件（约 73.0 MiB）。这个目录数字不包含安装器另带的源码 ZIP、GPL 与安装说明。已保留 .NET 许可及第三方声明。

本包内置 .NET 10.0.13 x64，不需要另装 .NET。Windows App Runtime 部署方式保持现状。
这是本地 0.9.6 源码的独立优化实验。另一个会话的 0.9.7 共享运行时版已按用户要求撤回；本轮未操作其文件。此预览没有上传或覆盖正式 Release。

## 采用的方法

入口是 packaging/CompactPackage.targets 与 CompactRoots.xml，通过命令行显式导入；默认项目没有启用裁剪。
完整复制 Native/Core、WinRT/WinUI 投影、动态 C#、表达式树及 JSON 共 9 个关键程序集，逐字节核对通过。
启用 JSON 反射及内置 COM，保留 CoreLib 全部成员，以及 XML、HTTP、进程、文件等兼容契约。
CoreLib 从 16,033,576 降至 5,463,040 字节；类型、字段、方法、参数等元数据行数一致，主要去除了预编译代码体积。没有据此宣称启动或内存改善，JIT 成本需要另测。
其余由 ILLink 静态依赖处理；没有人工删除未知 DLL、隐藏警告或修改硬件准入。

淘汰了实际复现 JSON 匿名对象变空、日志字段丢失，以及 COM 禁用/原生崩溃的激进方案。旧约 28 MiB 实验目录不是本候选。
最终发布仍输出 180 条 IL 警告行：IL2026 141、IL2081 35、IL2072 3、IL2067 1。完整日志留存。保留策略和测试覆盖了已知动态契约，但不等于证明所有反射路径安全；继续缩小需要逐项静态化动态契约，不能只屏蔽警告。

## 已验证

- 在候选本地运行时执行 70 后台、32 诊断、10 风扇编辑、9 布局、7 OSD 框架、18 准入、13 更新检查，共 159 项通过。布局含 300 组样本。
- 11 组隐藏原生探针通过：配置/匿名嵌套 JSON/异常日志、WinRT、主题/XAML/图标、54 个页面控件树、只读 Task Scheduler COM、Rust ABI 与风扇表。
- 隐藏探针重复 5 轮全部成功，额外构建 270 个页面控件树。没有激活可见窗口或 Computer Use。
- 最终产品 Core/运行时 DLL 与探针所用版本逐字节相同。最终产品恢复原 App 入口和管理员清单，不含测试入口；正式产品本体未实际启动。
- 使用最终本地运行时，通过 HTTPS 下载公开旧安装包并核对长度/SHA256；安装器启动次数为 0。发行目录来自已保存的真实 GitHub 响应，未把认证令牌嵌入程序；不声称本轮匿名 API 请求成功。
- 285 项原 Native/Core 源文件资源哈希未变，对应源码 ZIP 一致；XBF/PRI、原版素材、桥接、关键依赖和许可保留。原正式 0.9.6 安装包哈希不变。
- 安装器编译成功。升级清理只列出 119 个已知旧运行时 DLL 名，不使用数据/插件通配删除；该清理尚未真实执行。

后台测试宿主为适配缩减运行时，去掉了未执行的实机写入分支，并将控制台输出改为文件；70 项后台断言保留。隐藏 WinUI 探针采用独立 asInvoker 清单，正式产品权限未降低。测试代码、日志和结果位于 evidence/package-optimization 与 work/package-optimization。

## 尚未验证及后续

真实安装/升级/卸载、可见界面裁切和输入、完整权限流程、实机写入与回读、长期内存趋势和启动性能均未验收。因此交付名为 Compact Preview，没有把它改成生产默认。
预览保持该 0.9.6 源快照。另一会话曾验证更新助手 SHA256 在特殊 PowerShell 模块环境下的替代实现，但未回迁主源码，后随独立 0.9.7 撤回。该环境下助手仍可能失败，本轮下载验证没有覆盖安装助手执行。后续正式采用应先修复并补测此路径，再合并到届时最新功能基线，重跑本报告检查及真实安装验收。
继续精简可优先将 JSON/动态 COM 改为明确静态契约，逐个减少保留根；Native AOT 与 C++/WinRT 是独立路线，不与此包混称。

## 复现与来源

对应源码包内 COMPACT-BUILD.txt 给出发布命令；installer-compact-preview.iss 是相对路径安装器配方。需要 .NET SDK、WinUI 构建工具、Rust 和 Inno Setup。不要直接运行主 build.ps1 覆盖同版本正式包。
