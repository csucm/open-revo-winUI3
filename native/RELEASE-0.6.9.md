# Open-Revo 0.6.9

当前待手动测试和发布的候选包。程序、安装器、关于和更新器统一使用 0.6.9。测试通过后再上传 GitHub。

- 修正大面板最小尺寸处理顺序，先经过框架再设置限制；最小宽度 900 DIP，为总览四列保留空间。保留 DPI、工作区上限、原最小高度和 mini 策略。
- CPU/GPU 磁贴增加型号行，保留既有指标，超长单行省略并提供完整提示，复用现有身份/采样。
- 修复 NVIDIA 独显 NVML 路径缺少型号字段的问题；名称与指标来自同一显卡。显存统一标注 GB，容量读数沿用现有口径。
- 修复已验证 Project16 的电池档位误禁用：保留正常 60/55 或 80/75 阈值、而选择字节回长效标记时，按本机已验证协议准入。其他项目和异常组合保持拒绝，写前状态比较与回读不变。
- 电源页电池图下显示文字，左右两栏不随窄窗下移。机身模式键按办公/均衡/狂暴三档循环，软件自定义补原白色指示。
- 拖动与交换中的图标置于页面顶层，跨小面板预览和控件库边缘保持可见；保留现有让位、交换和撤销逻辑。
- 纳入此前模式切换、切屏后亮度重读、亮度拖动即时读数、Bug 网页提交、关于赞助/交流群、托盘精简、mini 唤醒右下及已批准自定义/拖动功能。

交付为 `Open-Revo-0.6.9-Setup-x64.exe` 和本次完整 GPL 对应源码，共享 .NET 10 x64 / Windows App Runtime。构建、包静态核对和实际验收分别记录。不同机型、DPI、真实按键、灯色和电池切换仍以实机反馈为准。本轮不启动、安装、自动测试或上传。
