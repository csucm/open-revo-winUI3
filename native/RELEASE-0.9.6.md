# Open-Revo 0.9.6

2026-11-01 · Windows x64 · WinUI 3 社区重写版

- 灯光与设备页恢复原版工作台排列：设备标签、灯效、亮度、紧凑色点与自定义颜色；保留真实回读和亮度端点修正。
- 显卡三张模式卡片等高，恢复原版闪电/层叠/断电图标、芯片标识与说明。mini共用这些素材，保持现有布局。
- 仅调整电池健康区域：左侧三档模式，右侧原版电池示意图；按实际电量与供电状态更新，支持减少动画。
- 包含OSD白框的窗口框架修正，保留原版OSD素材、预览文字和Caps提示。保留0.9.5设置页原排版、退出失败恢复与资源趋势日志。

## 验证与范围

固定Core 0.9.5及提交72e98685b2c0538fa0a58409a6bcce9e7b6336f7，保留本地调色补丁。没有升级原Core或扩大硬件写入能力。灯光色值与保存格式保持兼容。图标直接来自原版锁定的lucide-react 0.460.0，附许可证。

发布检查与完整性结果见随交付附带的核验记录。未运行WinUI桌面验收，等高、窄窗、主题、Flyout、电池示意及真实OSD白框消失仍待用户确认。隐藏Win32框架回归不替代真实WinUI视觉。远端机型功能、长期资源增长和安装后的实际交互未验证；本版不宣称内存泄漏已经修复。

## 安装

安装前请从旧版托盘完整退出，运行Open-Revo-0.9.6-Setup-x64.exe。需要现有.NET 10 Desktop Runtime及Windows App SDK依赖。安装器同时提供GPL完整对应源码；旧包保留。开发过程中没有自动安装、关闭窗口或修改自启。
