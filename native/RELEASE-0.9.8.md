# Open-Revo Native 0.9.8

Windows x64 · 社区预发布版 · 2026-11-03

## 本版变化

- 按已确认的网页设计重写大面板、mini、详情页与设置页。继续使用原生 WinUI 窗口，不启动 WebView2 网页宿主。
- 磁贴支持编辑、拖动、移除、保存和取消。导航支持手动展开与响应宽度自动折叠。
- 调整 mini 控件对齐，保持无滚动的紧凑布局。设置增加动效速度和“关于”内的检查更新入口。
- OSD 三种样式使用窗口裁切与整体透明度过渡，修复白色背景闪帧的显示路径。导航缩放复用图标，避免反复重建。
- 键盘背光 OSD 只显示“静态单色”“彩色循环”“关闭背光”等四字状态，去除档位及颜色值。
- 各档动效时长减半。大小面板连续切换时不隐藏窗口，并保持完整窗口背景覆盖；图标复用已载入的 SVG 源。
- 保留后台 Caps 提示、配置原子保存、更新校验、正式圆角图标和原安装目录浏览行为。

## 安装与源码

安装包：`Open-Revo-0.9.8-shared-Setup-x64.exe`。
GPL 完整对应源码：`native-source-0.9.8-shared.zip`，也随安装包放入安装目录的 source 文件夹。

继续使用共享 .NET 10 x64 Desktop Runtime。安装器在缺失时提供微软官方依赖下载引导。Windows App Runtime 2.5+ 为独立依赖。新安装默认当前用户 LocalAppData/Programs/OpenRevo，升级沿用已有目录。安装前请从托盘正常退出旧版。

插件仍在开发中。目前提供内置原生示例及受限 API，不提供第三方插件市场或旧网页插件宿主。

## 验证边界

发布构建的检查结果与文件核验保存在 `evidence/package-0.9.8-shared`。此前隔离界面检查覆盖页面布局、导航复用和三种 OSD 透明度进出；它们不等同于所有桌面环境的逐帧视觉验收。

没有自动安装、上传、关闭用户程序或执行硬件写入。真实安装升级、不同显卡驱动下的实屏动画和长期资源占用仍需用户验证。本版没有新的内存降幅基准。
