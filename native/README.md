# Open-Revo 0.9.8 原生面板

运行上一层 `Open-Revo-0.9.8-shared-Setup-x64.exe` 安装或升级。当前使用 WinUI 3 窗口和按已确认设计重写的自绘控件，不启动 WebView2 网页宿主。采用共享 .NET 10 x64 Desktop Runtime，安装器提供依赖检测与下载引导；Windows App Runtime 2.5+ 仍为独立依赖。主程序整体管理员运行，手动启动可有一次 Windows 授权。说明与限制见 [RELEASE-0.9.8.md](RELEASE-0.9.8.md)。

大面板总览按参考重排并修复缩放居中，性能自定义采用CPU/GPU并排、风扇在下方的独立子页，支持原版内置方案及管理工具栏。快捷开关和按需监测复用受限Core桥接，显示CPU功耗、显存占用与实际显存时钟；OSD原生提示可关闭。一键强冷位于总览底部快捷区。PawnIO仅做可行性验证，没有接入或安装。

用户已认可当前迷你面板。小窗口启动停靠右下角，正方形按钮展开大面板；刷新率读取真实最低/最高及中间档位，无额外档位隐藏更多。亮度、背光、性能、充电与快捷控制保持局部更新。Win键锁保留硬锁和切换中过渡态，应用退出不主动解除已确认的硬件锁。

极客CPU/GPU功耗、温控、超频和自定义风扇曲线已有编辑与受限提交，点击应用才写入。高危调校真实写入、其他键盘类型、热切换、完整扩展/水冷等尚未全面验证或迁移，不宣称原版全部功能等价。

机型准入改为原Core平台探测、声明式驱动及真实通道握手，不再限制为本机DMI、固定BIOS和项目16。按通道和能力开放控制，保留冲突、串行、参数、审计和回读检查。GM5HG0A及GM6AQ7C等远端机型仍需新版实测；声明式通道的部分原版功能尚未完成原生适配。屏幕按Windows活动内置路径动态识别，不再限定本机面板ID；虚拟、外接、克隆及多候选继续拒绝。GPU固件保存往返已经实测；真正重启切换未测试，热切换未开放。

安装保持当前用户路径和旧AppId。首装沿用默认自启，升级保留已有选择；旧Run项只在路径完全匹配时，经一次管理员授权迁移为最高权限登录任务。自启开关仍在设置页，未更改原版任务，不安装驱动、服务或证书。用户数据默认保留在本地应用数据目录，设置支持复制校验迁移和备份式清除。大面板最小化切换为可见mini，X隐藏到托盘，mini最小化仍隐藏到托盘。点击图标唤醒，右键托盘菜单退出；升级前先从旧版托盘完整退出。设置页已整合原版系统功能，主题、OSD和唤醒形态会记忆。离电限制默认关闭，启用需确认；不放宽数值/机型保护。开发版更新检查用户仓库的native-v*发布；点击下载并安装后，先校验SHA256，正常退出后启动安装。

保留GPL-3.0-or-later许可，安装目录的 `source/native-source.zip` 包含当前完整对应源码。固定上游Core 0.9.5及本地修改在 `src/OpenRevo.Upstream`，C ABI在 `OpenRevo.CoreBridge`。`build.ps1` 接受DotNet、Cargo、Iscc路径；`-Offline`使用既有锁文件和缓存离线构建。Windows上需.NET 10 SDK、Windows SDK、Rust MSVC工具链及Inno Setup；脚本运行检查、发布、编译桥、打源码包并生成安装器。

0.9.4增强基础诊断及跨进程启动日志，报告升级schema 3；修正自启语义回读和动态内置屏识别、OSD边缘样式及图标主题同步。亮度在拖动中提交，mini采用已选定的等宽滑杆；大面板移除额外切换按钮。日志路径和回测说明见DIAGNOSTICS.md。实际端点、主题、OSD外框、实时响应及远端协议仍待实机确认，详见RELEASE-0.9.4.md。


0.9.4加入轻量返回、实际来源恢复、风扇坐标与节点可视化、图标光学对齐及调色线程/重复写入修正。风扇编辑仍只改草稿，色彩修改保留参数、基线与回读保护；实际窗口及六预设/Gamma效果仍待回测。
