## 方案来源和保存

桥接只读查询18调用原版 Core 获取四个内置方案：静音狂暴、均衡电竞、极致静音、极限狂暴。该查询不启动上游完整后台，不写硬件。

Native 的 `TuningPresetStore` 将 CPU 参数按本机已确认的原厂寄存器计算，GPU 按已读能力适配，曲线按既有保护验证；末点80/90%的原版方案提高至100%，最迟95°C达到。界面列出适配说明。方案选择和参数编辑仅变更内存草稿。

工具栏支持复制草稿新建、保存、恢复当前内置方案、重命名自定义方案、JSON导入导出、打开目录、删除自定义方案。内置不可重命名/删除，恢复的是本机适配后的默认值。保存到 `%LOCALAPPDATA%/OpenRevoNative/profiles`（由 AppData.DirectoryPath 决定），独立于官方数据。切换方案保留本次会话草稿；持久保存需点击保存图标。重新读取明确替换为当前硬件草稿。

文件上限1MiB，名称1–12字符；存储仅接受固定内置ID或生成的 user_GUID，原子替换文件，损坏记录跳过。删除移入同目录 trash，保留恢复可能。导出包含完整 Native 参数及原版 profile 字段，导入支持两者和旧 Native 草稿；原版参数按本机适配，Native精确参数不静默放宽。导入后仍须点击“应用极客调校”才写硬件。
